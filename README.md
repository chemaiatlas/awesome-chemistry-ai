## MCP Servers

Model Context Protocol servers that connect AI clients and agents with chemistry, biology, literature, structural biology, and materials-science tools or data sources.

- **RDKit MCP Server (TandemAI)** — MCP access to RDKit-based cheminformatics capabilities. [Source](https://github.com/tandemai-inc/rdkit-mcp-server)
- **UniProt MCP (cyanheads)** — MCP integration for UniProt protein data. [Source](https://github.com/cyanheads/uniprot-mcp-server)
- **RCSB MCP (cnyambura)** — MCP integration for RCSB Protein Data Bank resources. [Source](https://github.com/cnyambura/rcsb-mcp)
- **Materials Project MCP** — MCP access for materials-science data and workflows.
- **PubMed MCP** — MCP access for biomedical literature discovery and retrieval.
- **Benchling MCP** — MCP integration for Benchling-related scientific workflows.
- **PocketScout** — MCP-oriented tooling for protein-pocket and structure workflows.
- **NovoMCP** — MCP tooling for scientific and chemistry-related workflows.
- **ChemCP** — MCP tooling focused on chemistry workflows.

> Browse the full and continuously updated collection on [ChemAI Atlas](https://chemaiatlas.com/).

## AI Agents

Agentic systems designed for chemistry, materials science, drug discovery, and scientific research.

- **ChemGraph** — Agentic chemistry and scientific reasoning workflows.
- **MDCrow** — Agent framework for molecular and scientific tasks.
- **ChatMOF** — AI agent focused on metal-organic frameworks and materials research.
- **SciAgents** — Multi-agent workflows for scientific discovery.
- **ChemAgents** — Chemistry-focused agent project.
- **ChemAgents** — A second independently maintained chemistry-agent project cataloged by ChemAI Atlas.
- **STELLA** — Agentic system for scientific research workflows.
- **DrugAgent** — AI-agent workflows for drug-discovery tasks.

## AI Skills

Reusable scientific capabilities that can be composed into AI-assisted research workflows.

- **RDKit** — Cheminformatics and molecular manipulation.
- **Datamol** — Molecular data handling and cheminformatics utilities.
- **nmrglue** — NMR spectroscopy data processing.
- **Pymatgen** — Materials analysis and computational materials science.
- **Cantera** — Chemical kinetics, thermodynamics, and transport.
- **pycalphad** — Computational thermodynamics and phase-diagram calculations.
- **ASE** — Atomic Simulation Environment for atomistic simulation workflows.
- **Phonopy** — Phonon calculations and lattice-dynamics workflows.
- **ReacNetGenerator** — Reaction-network analysis from molecular dynamics.
- **rdkit-agent** — RDKit-oriented capabilities for agent workflows.

## APIs

Scientific APIs that can be used directly by AI applications, agents, and research automation.

- **PubChem PUG REST** — Programmatic access to PubChem chemical information.
- **RCSB PDB Data API** — Programmatic access to Protein Data Bank structure and metadata.

## Selection Criteria

A resource is generally a good fit when it:

- has a clear connection to chemistry or an adjacent scientific field;
- provides meaningful AI, ML, agent, MCP, API, or scientific-computing functionality;
- has a verifiable official source, repository, publication, or product page;
- is useful to researchers, students, developers, or scientific teams;
- is sufficiently documented to understand what it does.

This repository is curated. Inclusion is not an endorsement.
