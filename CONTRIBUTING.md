# Contributing to Awesome Chemistry AI

Thanks for helping improve **Awesome Chemistry AI**.

This repository is a curated list maintained by [ChemAI Atlas](https://chemaiatlas.com/). Contributions are welcome from researchers, developers, maintainers, students, and users of chemistry-AI tools.

## What You Can Contribute

You can help by:

- suggesting a new resource;
- correcting inaccurate or outdated information;
- fixing broken links;
- improving descriptions;
- suggesting a better category;
- adding an official publication, repository, or documentation link.

## Resource Requirements

A submitted resource should:

1. Be clearly relevant to chemistry, cheminformatics, molecular modeling, drug discovery, materials science, structural biology, or a closely related scientific field.
2. Have a meaningful AI, ML, agent, MCP, API, scientific-computing, or research-automation component.
3. Have a verifiable official source.
4. Be sufficiently documented to understand its purpose.
5. Not be spam, an affiliate-only page, or a thin wrapper with no clear scientific value.

Both open-source and commercial resources may be included when they are useful to the community.

## Preferred Entry Format

Please keep entries concise.

```md
- **Project Name** — One-sentence factual description. [Source](https://example.com/)
```

When both an official website and source repository are useful:

```md
- **Project Name** — One-sentence factual description. [Website](https://example.com/) · [GitHub](https://github.com/example/project)
```

## Descriptions

Descriptions should be:

- factual;
- neutral;
- short;
- specific about what the project does;
- free of promotional claims.

Avoid phrases such as:

- "the best"
- "revolutionary"
- "industry-leading"
- "game-changing"

unless the wording is part of a directly relevant official name or verifiable designation.

## Pull Requests

For a Pull Request:

1. Add the resource to the most appropriate section.
2. Keep alphabetical or logical ordering where practical.
3. Include an official source.
4. Explain briefly why the resource belongs in this list.
5. Avoid unrelated formatting changes in the same PR.

## Corrections

If a project has changed name, URL, maintenance status, license, or scope, please open a correction issue or submit a Pull Request.

## Relationship with ChemAI Atlas

Resources listed here may also appear in the main [ChemAI Atlas](https://chemaiatlas.com/) directory.

The GitHub repository is intentionally concise and community-oriented, while ChemAI Atlas provides richer metadata, categorization, discovery, and guides.

## Code of Conduct

Be constructive and respectful when discussing projects or reviewing contributions. Focus criticism on verifiable project information, not individuals.
